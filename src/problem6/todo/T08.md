# T08 — Security & adversarial test suite

**Epic**: Problem 6 — Live scoreboard
**Depends on**: T04 (complete path), T03 (Redis layer)
**Delivers**: proof that the anti-cheat design holds under attack.

## Context

The feature's entire value proposition is "malicious clients cannot inflate
their score." This suite is a **required CI gate**, not a nicety. Every test
below targets a row of the threat model in `../docs/DESIGN.md` §8.

## Tasks

1. **Token forgery** — craft a JWT with the right header but wrong secret;
   attempt `complete` → `401`, zero credit (integration).
2. **Points tampering** — take a valid token, decode, change the `points`
   claim, re-sign with the wrong secret → `401`. (Re-signing with the right
   secret is impossible by construction — assert the signature check is what
   fires.)
3. **Replay** — `complete` the same `actionId` twice → `200` then
   `409 REPLAY_DETECTED`; `scores` unchanged after the second call
   (integration).
4. **Concurrent race** — 50 parallel `complete` calls for one `actionId` →
   exactly one `200`, 49 `409`, exactly one `score_events` row, score +N
   exactly once (integration).
5. **Cross-user replay** — user B completes with user A's `actionId`/token →
   `401 INVALID_TOKEN` (claims bound to `sub`).
6. **Pending-action flood** — 1k parallel `start` calls from one user →
   capped at 10 pending → `429` beyond (integration, run with a disposable
   Redis key space).
7. **Action-type frequency abuse** — hammer `start` for the same
   high-value `actionType` beyond the registry's rate rule → `429`/`400`
   (integration).
8. **ZSET tampering** — write garbage directly into `leaderboard:*` keys →
   rebuild job (T03) restores correct values from Postgres; drift alert
   fires (integration + fake alert sink).
9. **ZSET-down behavior** — simulate Redis unavailability on the leaderboard
   read path → `503`, never a wrong/partial answer (integration with a
   broken store injected).

## Acceptance criteria

- [x] Every test above exists, is repeatable, and targets a distinct threat
      row (traceability comment links test → threat).
- [x] Suite runs against real Postgres + Redis via docker-compose, in
      isolated key/table namespaces per run.
- [x] Wired into CI: merge blocked on this suite passing.
- [x] `npm run typecheck` clean.

## Out of scope

- Load/soak performance (T09).
- UI-level tests.
